# PR前セルフレビューチェックリスト

> PR を Open する前に、自分の差分（`git diff main...HEAD`）に対して以下を確認する。
> このチェックリストは `docs/08-結果/summary.md` §6（AIレビュー比較の知見）に基づく。
> AIレビュー（CodeRabbit / cubic）は「補助」であり「代替」ではない。両ツールが取りこぼした問題（例: A7 レートリミット）を自分で拾うための最終防線。

## 実行方針
- **機械で検出できる項目**: ESLint / `tsc` / grep / secret scan に任せる（pre-push フック・CI で自動実行）。
- **文脈推論が必要な項目**: AI（Claude Code の `/self-review` 等）または自分の目で確認する。

---

## チェック項目

### 📦 PR粒度（最初に確認 — 目指す開発フロー §5-1）
- [ ] **1関心事**: 1PR = 1つの関心事。リファクタと機能追加・バグ修正を混ぜていないか（タイトルが「〜と〜」になるのは分割サイン）
- [ ] **サイズ**: 追加行数は **+400行まで**（200行以下が理想）を超えていないか。超える場合や関心事が混ざる場合は分割する（関心事単位・リファクタと機能の分離・スタックPR可）

> 根拠: SmartBear の調査では 200〜400行を60分でレビューしたときに不具合の 70〜90% を発見。400行を超えると検出率が急落（21万PR超の分析でも同傾向）。粒度が小さいほどレビュー精度・サイクル速度・ロールバック容易性が上がり、AIレビューの文脈把握も正確になる。

### 🗄 DBアクセス
- [ ] **N+1**: ループ内でクエリを発行していないか（`for` / `map` / `Promise.all` 内の個別取得に注意）。
- [ ] **アトミック性**: 「検査 → 更新」が非アトミックでないか。インクリメント等は `increment` や atomic 命令を使う。
- [ ] **制約**: 一意性はアプリ側チェックでなく DB の `@unique` 制約で守っているか。

### 🔐 認可・認証
- [ ] **認可**: `req.user` の権限・リソース所有者（`authorId` 等）を毎回照合しているか（IDOR）。
- [ ] **管理機能**: 管理者ロールのチェック（`requireAdmin` 等）を抜けていないか。
- [ ] **試行制限**: 認証系エンドポイントにレートリミット/ロックアウトはあるか（**A7: AIが見逃しやすい**）。

### ⌨️ 入力
- [ ] **バリデーション**: `req.body` / クエリを未検証で使っていないか（zod 等のスキーマ検証）。
- [ ] **インジェクション**: ユーザ入力の SQL/HTML 結合がないか（`$queryRawUnsafe`・`ORDER BY` 結合・`dangerouslySetInnerHTML`）。

### 🔑 秘密
- [ ] **ハードコード**: ソースに秘密・APIキー・トークンがないか。env 必須化したか。
- [ ] **フロント**: 秘密をブラウザバンドル/localStorage に入れていないか。

### ⚡ 並行・競合
- [ ] **レース**: 同一リソースへの並行書き込みは制約/atomic/トランザクションで守れているか。
- [ ] **タイミング**: パスワード/トークンの比較は定数時間か（`===` でないか）。

### 🛠 運用・堅牢性
- [ ] **ログ**: ログに機密（body/headers/パスワード）が混じっていないか。
- [ ] **情報漏洩**: エラー応答に `stack`/内部メッセージを漏らしていないか。
- [ ] **リソース**: ファイル/ストリーム/コネクションを確実に閉じているか（`finally` / `using`）。
- [ ] **デバッグ**: デバッグ機能が本番で有効になっていないか（`NODE_ENV` ガード）。

### 📅 日時
- [ ] **タイムゾーン**: 日時は UTC/ISO8601 で扱い、サーバローカルTZに依存していないか。

### 🧹 型・規律
- [ ] **型安全性**: `any` / `@ts-ignore` はないか。`tsc --noEmit` が通るか。
- [ ] **単一責任**: 1関数が長大になっていないか（バリデ・保存・通知等の混在）。
- [ ] **DRY**: 同じ処理が複数箇所に重複していないか。

## AIレビューでも取りこぼされやすい問題（本次の知見）
- **A7 ログインのレートリミット**: CodeRabbit も cubic も見逃した。運用系は自分で確認。
- **N+1 / レース / タイミング攻撃**: CodeRabbit が見逃した。文脈推論が必要な問題は慎重に。
