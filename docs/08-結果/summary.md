## 2. cubic 集計

| 指標 | 値 |
|---|---|
| 満点 | 54点（27問題 × 2） |
| cubic 得点 | **53点** |
| 完全検出（2点） | 26件 |
| 部分検出（1点） | 1件（D3） |
| 未検出（0点） | 1件（A7: レートリミット欠如） |
| Recall（完全検出） | **26/27 = 96%** |
| 指摘総数 | 58件（PR-1=14, PR-2=15, PR-3=10, PR-4=19） |

### cubic の特徴
- **検出力が極めて高い**: N+1・SQLi・IDOR・レース・TZ・XSS など、高難易度を含む広範な問題を取りこぼさない（A7のみ完全見逃し）。
- **修正案が具体的**: 問題の本質に加え、bcrypt/argon2・DOMPurify・Prisma `increment`・UNIQUE制約など、実装可能な修正を提示する（2点判定が大半）。
- **追加の正当な指摘が豊富**: docs/05 外の実務的問題（JWT有効期限・cookie secure属性・ユーザ列挙・CSV formula injection・フロントの credentials 欠如・race condition 等）を多数検出。Precision を下げるような有意でない指摘はほぼない。
- **D3 は部分検出**: `@ts-ignore`/デッドコード（`INTERNAL_DEBUG_KEY`）は指摘したが、`any` の多用そのものは明示的に指摘しなかった（実害の薄い型問題より実害のある問題を優先した結果と読める）。

## 3. CodeRabbit 集計

**保留中**。4 PR を連続トリガーしたことでリポジトリ全体がレートリミット（Pro Plus）に入り、すべての PR でレビューが実行されなかった（`Review rate limited` / `Review in progress` が1時間以上停滞）。ステータスページは正常。

→ CodeRabbit ダッシュボード（coderabbit.ai）でレートリミットの解消・ジョブのキャンセル/再実行を行い、落ち着いた後に再収集して本表の右列を埋める。

## 4. 暫定所感（CodeRabbit データ不足）

cubic は本サンプルにおいて **Recall 96%・Precision 高・修正案具体** という非常に高い水準。CodeRabbit はレートリミットの壁に阻まれ現時点で評価できておらず、比較の結論は CodeRabbit のデータ取得後に確定する。
